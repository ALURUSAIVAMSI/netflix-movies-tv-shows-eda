# Netflix Movies & TV Shows – Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python. The objective is to identify patterns and trends in Netflix's content library through data cleaning, statistical analysis, and visualization.

## Objectives

- Understand the structure of the Netflix dataset.
- Handle missing values and inspect duplicate records.
- Analyse Movies and TV Shows distribution.
- Identify countries contributing the most titles.
- Explore release-year trends.
- Identify the most common genres and content ratings.
- Present insights through meaningful visualizations.

## Dataset Information

- **Dataset:** Netflix Movies and TV Shows
- **Total Records:** 8,807
- **Total Columns:** 12
- **Format:** CSV

The dataset contains information about titles, directors, cast, countries, release years, ratings, durations, genres, and descriptions.

The original dataset was obtained from an external dataset source. Refer to the original source and its usage terms when accessing or redistributing the data.

## Key Findings

- Movies account for approximately 69.6% of the dataset, while TV Shows represent 30.4%.
- The United States has the highest number of country-title associations (3,690), followed by India (1,046).
- The year 2018 recorded the highest number of titles in the analysed release-year distribution, with 1,147 titles.
- International Movies is the most frequently occurring category, with 2,752 genre-title associations.
- TV-MA is the most common content rating, with 3,207 titles.

**Note:** Country and genre counts represent associations. A title can be associated with multiple countries and genres.

## Conclusion

This project provided practical experience in data preprocessing, missing-value handling, exploratory data analysis, statistical summaries, and data visualization using Python.

The analysis revealed useful patterns in Netflix's content distribution, geographical representation, release years, genres, and content ratings.

2. Download the Netflix dataset from its original source.
3. Upload `netflix_titles.csv` to the Colab runtime.
4. Open `Netflix_EDA_Project.ipynb`.
5. Run the notebook cells sequentially.
